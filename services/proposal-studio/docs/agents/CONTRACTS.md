# Agent Contracts — Input, Output, and Slide Rules

This document defines the exact JSON contracts for the n8n agent system.

## Input Contract (Main Workflow Receives)

Any field may be missing or empty:

```json

    "requirements": ["string", ...],
    "raw_text_excerpt": "string (max 4000 chars)"

  "match": {
    "score": 0.91,
    "similar_projects": [
      {
        "name": "string",
        "client": "string",
        "year": 2025,
        "result": "string",
        "stack": ["string", ...],
```

## Standard Slide Order (13 Slides for Software/SaaS, 12 for Others)

| Order | ID | Slide | Owner | Blocks |
|-------|-----|-------|-------|--------|
| 1 | s1 | Synthèse exécutive | Agent 1 | text + kpis + bullets |
| 2 | s2 | Compréhension de vos besoins | Agent 1 | bullets |
| 3 | s3 | Solution proposée et conformité | Agent 1 | table (compliance matrix) |
| 4 | s3b | Architecture technique | Diagrams | image + bullets + sources |
| 5 | s3c | Modèle de classes | Diagrams | image + sources (only software/saas) |
| 6 | s4 | Nos atouts | Agent 5 | bullets |
| 7 | s5 | Plan de mise en oeuvre | Diagrams | image + table |
| 8 | s6 | Équipe et gouvernance | Agent 5 | table + bullets |
| 9 | s7 | Références pertinentes | Agent 5 | cards (max 3) |
| 10 | s8 | Support et SLA | Agent 5 | bullets |

**Fixed slides** (generated by platform, never sent by agents):
- Slide 0: Title slide (from `name`, `client`, `date`)
- Last slide: Thank-you + QR (from `qr_url`)

## Deck Spec (POST /api/decks)

```json
{
  "name": "string (required)",
  "client": "string",
  "date": "string",
  "language": "fr" | "en",
  "qr_url": "string",
  "theme": {
    "primary": "#hex",
    "secondary": "#hex",
    "background": "#hex",
    "fontHeading": "string",
    "fontBody": "string"
  },
  "slides": [
    {
      "type": "content",
      "title": "string (required)",
      "blocks": [...] (required),
      "notes": "string",
      "warnings": ["string"],
      "requiresApproval": boolean,
      "assumptions": ["string"],
      "catalogDate": "string",
      "sources": { "mermaid": "string", "drawio": "string" }
    }
  ]
}
```

**Unknown fields are rejected with HTTP 400.**

**Allowed deck fields**: `name`, `client`, `date`, `language`, `qr_url`, `theme`, `slides`

**Allowed slide fields**: `type`, `title`, `blocks`, `notes`, `warnings`, `requiresApproval`, `sources`, `assumptions`, `catalogDate`

## Block Kinds

### text
```json
{ "kind": "text", "text": "string" }
```

### bullets
```json
{
  "kind": "bullets",
  "items": ["string", ...],
  "bulletStyle": "disc" | "number" | "check"
}
```

### table
```json
{
  "kind": "table",
  "columns": ["string", ...],
  "rows": [["string", "string"], ...]
}
```
**All cells must be strings** (write numbers as strings).

### image
```json
{
  "kind": "image",
  "src": "/uploads/..." | "data:image/...",
  "caption": "string (optional)"
}
```

### cards
```json
{
  "kind": "cards",
  "cards": [
    {
      "title": "string",
      "text": "string",
      "image": "string (optional)"
    }
  ]
}
```

### note
```json
{ "kind": "note", "text": "string" }
```

### kpis
```json
{
  "kind": "kpis",
  "items": [
    { "label": "string", "value": "string" }
  ]
}
```

## Layout Rules and Limits

- **Content area**: 1720 x 760 px
- **Fonts never shrink below**: bullets 24px, tables 20px
- **Overflow**: Creates continuation slides "Title (1/2)", "Title (2/2)"
- **Table split**: Every 10 rows, repeating header
- **Bullet list split**: Every 12 items
- **Cards/KPIs**: Max 4 rendered (extras dropped silently)
- **Recommended limits**:
  - Bullets: max 6 items, 8-12 words each
  - Card text: ~35 words
  - Table: max 8 rows with short cells
  - At most 3 blocks per slide

## Slide Field Validation

- **Plain text only**: No HTML, no markdown, no emojis
- **Placeholder format**: Exactly `[TO FILL: <what is missing>]`
- **Language**: Match `tender.language` with correct accents
- **Titles**: Short and unique (deck-wide)
- **Numbers**: Must appear in input or be code-computed
- **Names**: Projects and certificates exactly from input
- **Claims**: Superlatives only if in `match.why_us`

## Response from POST /api/decks

Success (HTTP 200):
```json
{
  "id": "4c1d2e3f",
  "url": "/editor.html?id=4c1d2e3f",
  "warnings": ["string", ...]
}
```

Error (HTTP 400):
```json
{
  "status": "error",
  "message": "Validation failed against schema",
  "errors": [
    "slides[2].blocks[0].kind: unknown block kind 'chart'. Allowed: [...]",
    "slides[3]: unknown field(s) 'author'. Allowed slide fields are: ..."
  ]
}
```

Other errors:
- **401**: Invalid or missing `X-API-Key`
- **413**: Body too large (5 MB limit for decks, 25 MB for uploads)
- **503**: Regenerate webhook not configured

## Regenerate Webhook

Platform calls: `POST <REGENERATE_WEBHOOK_URL>`

Body:
```json
{ "deckId": "4c1d2e3f", "slideIndex": 1 }
```

Expected response (HTTP 200): **ONE slide spec** (without `id` field), exactly one slide, fitting one platform slide.

Timeout: 60 seconds (return current slide if timeout).

## Upload Endpoint

`POST /api/upload` (multipart, no auth)

Response:
```json
{
  "status": "ok",
  "url": "/uploads/8hex_filename.ext",
  "filename": "8hex_filename.ext"
}
```

Allowed extensions: png, jpg, jpeg, gif, webp, svg, mp4, webm, pdf, pptx (25 MB limit)

SVGs with `<script>`, `onload=`, `onclick=`, `onerror=`, or `javascript:` are rejected.

## Validation Mirror (contracts.js)

The `contracts.js` module mirrors `layout_engine.py` validation exactly:
- All allowed fields and block kinds
- Type checks (strings, arrays, booleans)
- Table cells must be strings
- Cards need title and text
- KPIs need label and value
- bulletStyle must be disc, number, or check
- Unknown fields or kinds return errors

Additional checks:
- More than 4 cards/KPIs: warning
- More than 6 bullets: warning
- More than 10 table rows: warning
- HTML-like text or emojis: warning
- Long bullet text: warning

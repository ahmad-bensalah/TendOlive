Title: Ministry of Interior - Digital Licensing Portal (2023)
Type: past_project
Summary: Digital licensing and compliance tracking platform delivered for a government ministry, React + Spring Boot + PostgreSQL, 5 month delivery.

Client: Ministry of Interior (public sector, government)
Year: 2023. Duration: 5 months. Budget: 520,000 TND
Scope: online licence requests, licence tracking and renewal, compliance follow-up, analytics dashboard for managers, REST API integration with the national ID system.
Stack: React, Spring Boot, PostgreSQL, AWS hosting, Keycloak.
Team: Sami Trabelsi (PM, PMP), Ahmed Bouazizi, Karim Jlassi, Leila Hammami, Youssef Gharbi, Amira Belhadj.
Result: 40,000 licences processed in the first year.

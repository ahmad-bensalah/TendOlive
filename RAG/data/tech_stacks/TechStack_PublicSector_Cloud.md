Title: OliveSoft Public-Sector Web Stack
Type: tech_stack
Summary: OliveSoft's standard public-sector stack: React, Spring Boot, PostgreSQL, AWS, ISO 27001-aligned delivery process.

Front end: React (or Angular when the client requires it)
Back end: Java Spring Boot or Node.js, REST APIs documented with OpenAPI
Database: PostgreSQL
Hosting: AWS or Azure, Docker and Kubernetes, CI/CD
Security: ISO 27001-aligned delivery process, OWASP checks, Keycloak single sign-on
Used in: Ministry of Interior licensing portal, Municipality e-services portal.
